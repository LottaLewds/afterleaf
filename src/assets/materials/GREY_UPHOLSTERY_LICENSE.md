# Grey Upholstery PBR

Source: https://freepbr.com/product/grey-upholstery-pbr/

Creator: FreePBR / Brian

The source page describes this material as a free 2048x2048 PBR texture set
usable in game engines and 3D work. Commercial-use rights should be confirmed
with FreePBR before commercial distribution.

These game-ready derivatives use the supplied albedo and OGL normal maps. The
surface texture packs ambient occlusion in red, roughness in green, and
metallic in blue.
